# Protocol 4 notes (what this project takes from it)

Source: BC Protocol 4 for Contaminated Sites, *Establishing Local Background Concentrations in Soil*,
Version 15, effective June 19, 2026 ([PDF](https://www2.gov.bc.ca/assets/gov/environment/air-land-water/site-remediation/docs/protocols/2026-06-10_final_protocol_4_v15_signed.pdf)). Section 4, read 2026-11-26.

- **Option 1 (s.4.1):** use the ministry's Table 1 regional estimates. The study area is in **Region 1,
  Vancouver Island**, where Table 1 gives **copper 100** and **zinc 150** µg/g. **Arsenic is printed as
  "(4)"** in parentheses. v15 has no footnote that explains the parentheses, so this project reports
  "(4)" as printed and doesn't treat it as a comparable number.
- **Option 2b (s.4.2.1), the method this project imitates:** reference samples must be native material,
  not fill (rule a), not affected by contaminant sources, and show no human impact. Then:
  - "the local background concentration ... is the **95th percentile** concentration of the data set";
  - "**Outliers** must be identified using statistical methods and removed";
  - "If **duplicates** are included ... the average concentration ... counted as one sample";
  - the data should be "a single statistical population" (s.4.2.3 g).
- **Mineralization (s.4.2.2):** a known mineralized area that "has not been previously mined or disturbed" can
  count as natural background. So this project excludes samples near mines and quarries, but natural
  mineral showings don't exclude a sample.
- **PCOC (s.1.0):** "any contaminant which might be expected to occur at a site based on the historical use
  of the site". This definition is the basis of the land-use screening.

**What this project does not do:** it isn't an Option 1 or Option 2 submission. There's no qualified
professional, no director's approval, and no EDQAR-registered lab chosen for the purpose. The sample
depths are C-horizon (about 1 m), while Table 1 comes from near-surface samples. The results are a
student comparison exercise, **not for regulatory use**.
